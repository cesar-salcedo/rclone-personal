Rclone personal permite gestionar la cuenta de Google Drive autorizada por su titular mediante Rclone y la skill drive-manager de Codex.

Qué permite hacer

  • Subir y descargar archivos.
  • Consultar archivos y carpetas.
  • Preparar entregas en formato ZIP.
  • Obtener enlaces y compartir archivos por indicación del titular.

Cómo funciona

Rclone se ejecuta en el equipo del titular y se comunica con la API de Google Drive. El acceso se concede mediante el consentimiento de Google. La aplicación solicita permisos de lectura y escritura para realizar las operaciones indicadas por el usuario.

El flujo con Codex requiere aprobación explícita antes de borrar archivos, sobrescribir entregas o habilitar enlaces públicos. Los datos necesarios para las tareas que se encarguen a Codex pueden ser procesados por ese servicio.

Este sitio explica la aplicación. No contiene formularios de inicio de sesión ni recibe credenciales, tokens o archivos de Drive.
